5G Vehicular Multicast

LE-GRA MVP

LE-GRA is a research prototype for Learning-based Embedding Grouping and Resource Allocation. The project asks a focused question: can learned user representations group vehicular multicast users more effectively than simple CQI-only rules, especially when radio conditions look similar at the wideband level but differ in resource cost and temporal behavior?

Current Snapshot

The project now has a post-fix medium experiment rerun. After correcting the learner's embedding-normalization gradient, LE-GRA improved enough to beat CQI, resource-cost, and multi-feature k-means in aligned light and aligned medium settings, while ambiguous settings remain the hardest case.

Core Idea

Why this project matters

Traditional MBS grouping often relies on raw CQI or similarly shallow radio indicators. That works in clean settings, but it can miss important structure: two users may share similar current CQI while still needing very different RB costs because their RB-level profiles, mobility trends, and playback history are not the same.

LE-GRA tries to bridge that gap. Instead of grouping users only by one visible metric, it learns a richer embedding from channel history, RB statistics, mobility cues, and quality-related resource cost. The expected benefit is more meaningful multicast grouping and better downstream resource allocation under an RB budget.

Input view

Use CQI history, RB-level rates, mobility features, and resource-cost vectors instead of only current CQI.

Teacher signal

Generate pseudo-labels with an offline utility-driven teacher that searches grouping boundaries and solves video assignment with DP.

Learning target

Train a model to place users with similar multicast value into nearby representation space, then cluster them for allocation.

Current Progress

What has been completed so far

Implemented work

  • Built a synthetic vehicular MBS scenario generator with aligned, ambiguous, and mixed modes.
  • Constructed offline teacher grouping with contiguous boundary search over users sorted by service difficulty.
  • Integrated exact dynamic programming for group-level video-quality assignment under RB budget.
  • Implemented an MLP embedding model trained with pairwise contrastive loss.
  • Compared multiple baselines: no grouping, CQI k-means, resource-cost k-means, multi-feature k-means, offline teacher, and LE-GRA.
  • Added a separate experiment comparing DP allocation against a greedy allocator.
  • Added a second exploratory route using pairwise same-group prediction plus graph clustering.
Progress Assessment

Current stage

This project is no longer at the idea stage. It is already a functioning research MVP with experiments.

The strongest result so far is that the teacher + DP framework is clearly validated. The learned model is operational, but it has not yet consistently surpassed the strongest handcrafted or teacher-based baselines.

Main MVP result

LE-GRA runs end-to-end and can be evaluated fairly against baseline grouping methods on the same backend.

Allocation result

Exact DP outperforms greedy allocation, especially when good grouping candidates are available.

Modeling result

The pairwise graph idea is implemented, but it is still exploratory rather than the new best method.

Latest Evidence

What the August 5 rerun changed

The latest medium matrix rerun matters because it was executed after a learner correctness fix: backpropagation through embedding L2 normalization now uses the proper analytic gradient. This was not a cosmetic cleanup. It changed the research conclusion.

Before the fix, LE-GRA looked consistently competitive but rarely stronger than the best handcrafted baselines. After the fix, LE-GRA became the best non-teacher method in aligned/light and aligned/medium. It still does not dominate ambiguous settings, but the learner now shows real value instead of only theoretical promise.

Clear improvement

LE-GRA now beats CQI k-means, resource-cost k-means, and multi-feature k-means in aligned light and aligned medium conditions.

Still unresolved

Ambiguous scenarios remain the research bottleneck. There the learned embedding is improved, but not yet a stable winner.

Updated takeaway

The bottleneck is no longer “does the learner matter at all?” but “how do we make the learner robust under ambiguity?”

Teacher Design

Why the offline teacher does not use the global optimum

A natural question is why the offline teacher does not search the true global-best grouping among all possible user partitions. The reason is not that a stronger teacher is undesirable. The reason is that the full search space grows explosively with the number of users, so a global optimum is computationally unrealistic even for moderate scenario sizes.

If there are n users, then a true unrestricted teacher would need to evaluate every partition from 1 to Kmax groups. That search count follows Σ S(n, k), where S(n, k) is the Stirling number of the second kind. This is exponential in practice. By contrast, the current teacher first sorts users by resource-cost score and only searches contiguous cuts on that sorted line. The candidate count becomes Σ C(n - 1, k - 1), which is still expensive but polynomial in n when Kmax is fixed.

Global optimum

Search every possible partition of users. This is the cleanest theoretical target, but the search space grows too fast to support repeated scenario generation and training.

Current offline teacher

Sort users by service difficulty, search all contiguous boundaries up to Kmax, and use exact DP to score each candidate grouping under the RB budget.

Research value

This gives a strong, stable, and computable supervision signal. The teacher is not globally optimal, but it is a constrained optimum inside a realistic and interpretable grouping structure.

In other words, the teacher is designed as a tractable near-optimal supervisor. Its role is to generate high-quality pseudo-labels and define an upper reference for the student model, not to act as a deployable real-time algorithm. This is exactly what gives LE-GRA research value: if the student can learn to approach this strong offline teacher with much lower online decision cost, then the learned method becomes meaningful.

Future Plan

Where the project should go next

Strengthen the learner

Focus on model-selection and training quality: validation-based checkpointing, better pair sampling, and small sweeps over margin, hidden size, learning rate, and epochs to improve ambiguous-scene behavior.

Stress-test ambiguity first

Keep aligned cases as sanity checks, but shift experiment attention toward ambiguous scenarios where hand-crafted grouping and learned grouping are most meaningfully separated.

Scale only after the learner is credible

Do not jump immediately to larger `Kmax`, more seeds, or much bigger matrices. First make sure the learner has a stable claim over strong non-teacher baselines.

Then move toward realism

Once the learner story is convincing, connect the prototype to richer traces, broader system design, and the later thesis or paper architecture.
