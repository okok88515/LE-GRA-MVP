Research Direction Reset

From CQI-only Grouping to Resource-Cost and Multi-Feature Grouping

This project no longer centers on proving that LE-GRA is a universally superior learner. The main research story is now sharper: in vehicular multicast, grouping users by current CQI alone is too shallow, and richer feature views such as resource cost and multi-feature state are much better aligned with the true allocation problem.

In other words, the strongest outcome of this phase is not a broadly dominant learned model. It is a validated argument that feature representation matters more than the original CQI-only grouping assumption.

Current Position

The teacher-plus-DP pipeline is validated, CQI-only grouping is clearly insufficient, and the most credible practical methods now are resource-cost k-means and multi-feature k-means.

Main Question

What this research now claims

Old starting point

A natural first baseline is to group users by CQI. It is simple, intuitive, and commonly used.

What we learned

Users with similar wideband CQI can still have very different RB-level rate profiles, temporal quality conflicts, and effective service costs.

Current answer

Resource-cost and multi-feature grouping are more faithful to the true multicast allocation problem than CQI-only grouping.

Why CQI is not enough

The bottleneck is feature poverty, not only model weakness

Same CQI, different cost

Two users may look similar in current wideband CQI but still require very different RB budgets once RB-level profiles are taken into account.

Temporal state matters

Previous quality, mobility trend, and historical conflicts can change whether splitting is worthwhile. Those effects are largely invisible to a single CQI value.

Pipeline

The stable part of the system is the teacher + DP framework

Scenario generation

Build synthetic and coupled trace-like scenarios with CQI history, RB rates, mobility state, previous quality, and derived resource costs.

Offline teacher

Sort users by service difficulty, search contiguous grouping boundaries, and score each candidate using exact DP allocation under the RB budget.

Fair comparison

Evaluate CQI k-means, resource-cost k-means, multi-feature k-means, and LE-GRA on the same backend so grouping quality is isolated cleanly.

Method Ranking

The new method hierarchy

CQI k-means

Still a useful baseline, but now mainly a proof of what is missing when the feature view is too shallow.

Resource-cost k-means

This is the strongest practical baseline and the clearest next-step method. It captures the real cost of serving users, not just current radio appearance.

Multi-feature k-means

This is the richer representation track. It shows that strong grouping can already emerge from better features, even without a learned embedding as the main story.

LE-GRA Status

LE-GRA is no longer the main claim

What we can no longer claim

We cannot honestly claim that LE-GRA is a robust general solution that consistently beats strong handcrafted baselines across regimes.

What remains useful

LE-GRA helped reveal where the hard structure actually lies. It remains a meaningful exploratory branch, especially for narrow boundary regimes, but it should not dominate the project narrative.

Teacher Design

Why the offline teacher is constrained rather than globally optimal

The teacher is not globally optimal because unrestricted partition search is too expensive. A true all-partition teacher would require evaluating Σ S(n, k) candidates, which becomes impractical very quickly. The current teacher instead sorts users and searches only contiguous cuts, reducing the search to Σ C(n - 1, k - 1) for fixed Kmax.

This makes the teacher a tractable, interpretable constrained optimum. That is enough for research supervision and for defining a strong allocation-oriented reference line.

Phase-1 Takeaway

What this phase really delivered

Positive outcome

The project successfully moved beyond the original CQI-only intuition and established that richer grouping features, especially resource-cost views, are genuinely worthwhile.

Honest limitation

The learner branch did not mature into a broad winning method. That is not wasted work; it is a useful negative result that clarifies where the real value of the system lies.
