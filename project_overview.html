5G Vehicular Multicast

LE-GRA MVP

LE-GRA is a research prototype for Learning-based Embedding Grouping and Resource Allocation. The project asks a focused question: can learned user representations group vehicular multicast users more effectively than simple CQI-only rules, especially when radio conditions look similar at the wideband level but differ in resource cost and temporal behavior?

Current Snapshot

The project has already moved beyond concept drafting. A full synthetic research pipeline is running end-to-end, baseline comparisons are available, and follow-up experiments have started to test allocation strategy and a graph-based grouping alternative.

Core Idea

Why this project matters

Traditional MBS grouping often relies on raw CQI or similarly shallow radio indicators. That works in clean settings, but it can miss important structure: two users may share similar current CQI while still needing very different RB costs because their RB-level profiles, mobility trends, and playback history are not the same.

LE-GRA tries to bridge that gap. Instead of grouping users only by one visible metric, it learns a richer embedding from channel history, RB statistics, mobility cues, and quality-related resource cost. The expected benefit is more meaningful multicast grouping and better downstream resource allocation under an RB budget.

Input view

Use CQI history, RB-level rates, mobility features, and resource-cost vectors instead of only current CQI.

Teacher signal

Generate pseudo-labels with an offline utility-driven teacher that searches grouping boundaries and solves video assignment with DP.

Learning target

Train a model to place users with similar multicast value into nearby representation space, then cluster them for allocation.

Current Progress

What has been completed so far

Implemented work

  • Built a synthetic vehicular MBS scenario generator with aligned, ambiguous, and mixed modes.
  • Constructed offline teacher grouping with contiguous boundary search over users sorted by service difficulty.
  • Integrated exact dynamic programming for group-level video-quality assignment under RB budget.
  • Implemented an MLP embedding model trained with pairwise contrastive loss.
  • Compared multiple baselines: no grouping, CQI k-means, resource-cost k-means, multi-feature k-means, offline teacher, and LE-GRA.
  • Added a separate experiment comparing DP allocation against a greedy allocator.
  • Added a second exploratory route using pairwise same-group prediction plus graph clustering.
Progress Assessment

Current stage

This project is no longer at the idea stage. It is already a functioning research MVP with experiments.

The strongest result so far is that the teacher + DP framework is clearly validated. The learned model is operational, but it has not yet consistently surpassed the strongest handcrafted or teacher-based baselines.

Main MVP result

LE-GRA runs end-to-end and can be evaluated fairly against baseline grouping methods on the same backend.

Allocation result

Exact DP outperforms greedy allocation, especially when good grouping candidates are available.

Modeling result

The pairwise graph idea is implemented, but it is still exploratory rather than the new best method.

Future Plan

Where the project should go next

Strengthen the learning method

Improve representation quality with better labeling strategy, stronger model training, more stable validation, and ablation studies that show exactly when learned grouping beats CQI-only or resource-cost baselines.

Expand the experiment design

Run sensitivity studies for group count, scenario ambiguity, RB budget, and switching penalty. These results will make the argument more research-ready and reveal where performance saturates.

Move toward realistic traces

Replace purely synthetic generation with Simu5G or OMNeT++ traces so the project is grounded in more realistic vehicular channel behavior and traffic conditions.

Connect to the full system design

Integrate the MVP with the intended k-GBRM phase-2 allocation logic and turn the current prototype into a closer match for the final thesis or paper system.
