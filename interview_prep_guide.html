01

電梯簡報版本(30 秒)

「我的碩論用 CQI 做 k-means 分群來解決 5G 車載多播的資源分配問題。發表之後我自己延伸做了幾件事：先用 exact DP 把原本的暴力搜尋加速了一千倍；接著發現手刻更多特徵去做分群其實不穩定，深入查出是 k-means 對離群值敏感的問題；後來改用學習出來的 embedding 取代手刻特徵，並加了一個保底機制讓它保證不會比原本的方法差；最後還在真實的 Simu5G 模擬環境上驗證了這些發現，不只是紙上模擬。」
02

完整故事版本

起因

我原本發表的方法(k-GBRM)是純粹用 CQI 做 k-means 分群，刻意只看通道品質、不看人數，避免把好使用者跟差使用者混在一起。但這個設計有先天限制：CQI 只是單一數字，看不到移動軌跡、歷史通道變化、或分組後實際會消耗多少資源。我想知道如果分群不只看 CQI，是不是真的能做得更好。

核心概念

先嘗試最直覺的做法──手動把更多資訊(每個使用者在各品質等級下需要的資源量)當特徵直接餵給 k-means，但這條路後來被自己的驗證推翻了。於是改用一個小型神經網路，先學出一個 embedding，再對 embedding 做 k-means──分群本質還是 k-means，只是依據的空間是學習出來的。訓練這個 embedding 需要「正解」當監督訊號，也就是每個情境下真正最優的分組方式。

遇到的困難

  1. 算真正最優解太慢(窮舉需要 30 秒/情境)。後來發現這個問題有特殊結構(排序後最優解必為連續分段)，可以用動態規劃精確求解，把時間壓到 0.03 秒，快了一千倍，且是精確解不是近似。
  2. 手刻特徵餵給 k-means 不穩定──某些情境下贏 CQI，資源緊繃時卻輸得更多。深入查出是 k-means 對離群值敏感：少數通道極差的使用者的資源成本值會被裁切成同一個「不可行」的極端值，讓 k-means 誤把他們單獨挑出來，而不是在 CQI 真正該切的地方切。
  3. 即使換成學習出來的 embedding，仍會在少數情境下輸給純 CQI 分群──原因是每個訓練情境的樣本數有限，模型在「該不該把單一極端離群使用者獨立成一組」這種罕見邊界判斷上不夠穩定。解法是加一個保底機制：同時算 CQI 分群跟 embedding 分群兩者的真實效用，取較高的那個──這在數學上保證了「絕不會比 CQI 分群差」，因為 E[max(X,Y)] ≥ max(E[X],E[Y]) 恆成立，且只要兩者存在交叉(沒有誰完全支配誰)就會嚴格更好。而這個效用比較機制其實就是原本論文 Algorithm 2「試過所有候選、挑效用最高者」的同一個設計原則往外推一層。

贏在哪裡

整體平均贏 CQI 分群約 1%，但真正有意義的地方是：在 CQI 本身就有結構性盲點的情境(例如兩個使用者當下 CQI 接近但移動模式或通道歷史完全不同)，學出來的方法能贏 CQI 分群多達 10%，而且資源越緊繃差距越明顯；在 CQI 本身就足夠代表通道品質的一般情境，兩者表現持平，不會變差。不是「處處都好一點」，而是「在 CQI 看不到的地方，它能看到，其他地方不會變差」。

真實資料驗證(補充深度用)

除了合成模擬器，我還在真實的 Simu5G + SUMO(5G 網路模擬 + 車流模擬)環境上重新驗證了核心發現：resource-cost 分群法在 CQI 高度離散的真實情境下確實贏 CQI(+4% 左右)，在 CQI 集中(訊號普遍良好)的情境下所有方法趨於一致──這跟合成模擬器的結論、甚至跟我原論文對 low-dispersed 情境的結論方向一致，不是只在自己寫的模擬器裡才成立。

03

技術細節備查

LE-GRA 完整 pipeline：CQI 歷史(5 步)+資源成本向量 → 標準化 → 3 層 MLP(48→48→8 維，L2 normalize) → 對比學習(teacher 最優分組轉成 pairwise 標籤，同組拉近/異組推遠) → embedding 上做 k-means(k=1..Kmax 全試) → DP 選最優 k → 跟 CQI 分群比效用取較高者。

訓練規模：每個訓練條件 60 個情境、6 個 epoch、每次抽樣最多 160 對正/負樣本、學習率 0.01──刻意輕量，方便解釋。

exact DP 的定位：不是近似演算法，是精確解，前提是兩個結構假設──(1) 排序後最優解必為連續分段 (2) RB 是同質可互換資源(每組需要的 RB 數只跟選擇的品質等級有關，不跟哪些實體 RB 有關)。這兩個假設讓問題落在多項式可解的特例，不是文獻上證明 NP-hard 的一般情況。

04

誠實的邊界

被問局限性時直接講，不用迴避：

整體優勢幅度平均只贏約 1%，不是壓倒性優勢，優勢集中在特定情境。
手刻特徵基線resource-cost / multi-feature 已知不穩定，這是後續改用 embedding 的動機，不是遮起來的缺點。
真實資料樣本只有 15 個樣本、單一次模擬(沒有多個亂數種子)，是方向性佐證，不是嚴謹的統計確認。
LE-GRA 於真實資料沒有在真實資料上訓練測試過，15 個情境遠不夠訓練一個神經網路，這是誠實的 scope 邊界。
exact DP 的規模上限使用者數到數百人以上會變慢(約 n^2.3 成長)，windowed 版本還在探索中，不用主動提。
05

常見追問 Q&A

Q. 為什麼還要用 k-means？現在都用 deep learning 了。

k-means 本身不是問題，問題是分群依據的特徵。我把 k-means 保留當作分群的最後一步(可解釋、確定性)，但讓一個學出來的 embedding 來決定分群依據的空間，而不是手動設計特徵。這樣兼顧可解釋性跟表達能力。

Q. 你怎麼確定學出來的方法沒有過擬合、不會在真實環境失敗？

三層驗證──(1) pre-registered、非搜尋式的合成模擬器驗證，涵蓋 5 種情境模式 x 3 種負載，Holm 校正；(2) 針對 resource-cost/multi-feature 的機制做過落地案例分析，不只看統計數字；(3) 在真實 Simu5G + SUMO 資料上重新驗證，方向一致。

Q. 為什麼一開始選的手刻特徵方法後來被推翻？這代表方法論有問題嗎？

不是方法論問題，是誠實回報負面結果的紀律──我先驗證了它不穩定，深入找出離群值敏感的具體機制，用實際案例展示原因，這個過程本身比一次就找到乾淨答案更能展現排查能力。

Q. LE-GRA 會不會有時候比原本的 CQI 分群差？

單獨用的話會，我量化過原因(訓練樣本有限、罕見邊界判斷不穩)，並加了一個保底機制(取兩者效用較高者)從結構上保證不會比 CQI 差，這個機制本身有數學證明支持。

Q. 這個工作發表了嗎？

沒有，這是我發表論文之後自己延伸做的探索，用來加深對這個問題的理解，不是投稿內容。
