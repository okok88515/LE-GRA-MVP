LE-GRA Hard Regime Focused Report

這份報告只看目前最有研究價值的三個 hard regimes：q10、m4b、o8。 目的不是再把 easy cases 混進平均，而是回答一個更重要的問題： 為什麼你會覺得方法差距沒有很大？

現在的答案是：差距其實存在，但它主要集中在特定 transition window 與 final grouping failure 上； 如果只看大盤平均 utility，很容易被沖淡。

核心結論

q10: selector-dominated m4b: post-selector weak closure o8: LE-GRA grouping-path failure

所以「方法差距看起來不大」不是因為我們沒有成果，而是因為很多 hard cases 的差距不是體現在 全域平均，而是體現在很短的關鍵窗口、特定 weak pair、或 final grouping 是否塌掉。

目前最值得講的研究故事，不是「LE-GRA 全面大勝所有 baseline」，而是「teacher gap 可以被拆成不同 failure mode，並且用對應的最小修正逐步補回」。

為什麼你會覺得差距不大

  • 很多場景本來就不難。 easy snapshots 會把 hard snapshot 的差距平均掉。
  • utility 對結構錯誤不一定夠敏感。 尤其像 m4b，utility gap 很小，但 group signature 完全不是同一件事。
  • 有些 regime 的關鍵不是 baseline 數字，而是 LE-GRA 自己會不會在最後一步塌掉。 o8 就是最典型的例子。
  • 目前成果更像「找到 failure mode 與修正槓桿」，而不是所有方法在所有資料上都被一口氣拉很開。

這張表就是目前最能回答你疑問的地方：有些 case 的 utility 差距不大，但 grouping structure 差很多。 如果只看 utility，你會覺得大家都差不多；如果把 signature 與 pairwise 一起看，差距就清楚了。

現在最該收斂的方向

下一步不該是盲目擴大 matrix，而是把這三類 hard regime 先收斂成一套可重複使用的 decision rule：

  • 如果是 selector-dominated，先試 margin_aware。
  • 如果 weak top-k 已對，但 final grouping 還錯，優先試 candidate_anchor_hybrid。
  • 只有在 weak top-k 根本沒恢復時，才優先回去做 supervision / representation redesign。

換句話說，我們現在不是缺更多亂數實驗，而是要把「何時用哪個修正」整理成更清楚的方法論。
