研究主線重寫版

從 CQI 分群，收斂到 Resource-Cost 與 Multi-Feature

這個專案現在最重要的主線，已經不再是「LE-GRA learner 能不能全面贏過所有 baseline」， 而是更清楚的一個問題：在 5G vehicular multicast 裡，只看 `CQI` 夠不夠做有效分群？

目前的答案很明確：不夠。真正能比較穩定反映分群需求的，是 `resource-cost` 與更完整的 `multi-feature` 表示；LE-GRA 則比較適合被定位成一條 exploratory 路線，而不是主方法本身。

現在先記住三句話

第一，`CQI-only` 太粗。第二，`resource-cost` 已經被反覆證明有價值。 第三，`multi-feature` 與 `resource-cost` 才是目前最穩、最適合當主角的方法線。

第一階段定位

  • Teacher + DP framework 已驗證成立。
  • 分群的核心進步來自 richer feature，不是 learner trick。
  • LE-GRA 保留成補充分析，不再當主結論主角。
核心問題

這個研究真正回答了什麼

起點

一開始最直觀的做法，是用目前的 channel 品質，也就是 `CQI`，把使用者分群。 這很自然，也很常見，但它其實只看到「表面上的無線品質」。

發現

真正影響 multicast grouping 的，不只是 wideband CQI， 還包括 RB-level rate profile、歷史品質衝突、移動趨勢，以及每個使用者對資源的實際消耗。

收斂

所以現在最合理的主線，不是繼續證明 learner 多強， 而是證明 `resource-cost / multi-feature` 比 `CQI-only` 更接近真實分群需求。

研究流程

整個方法脈絡，用故事講清楚

先建立可控的場景

我們先產生 synthetic 與 coupled trace-like 場景，讓每個使用者都有 `CQI history`、`RB-level rate`、mobility、previous quality，以及可推導的 resource cost。

再做一個很強但很慢的 offline teacher

Teacher 不是用來部署的，而是研究中的參考上界。 它會先排序使用者，再搜尋 grouping 邊界，最後用 exact DP 算每種 grouping 的 utility。

用同一個 backend 公平比較方法

不管前面是 `CQI k-means`、`Resource-cost k-means`、`Multi-feature k-means` 或 LE-GRA，最後都送進同一套 DP allocation。這樣比較的是 grouping 本身，而不是 allocator 差異。

最後不是 learner 勝出，而是 feature 勝出

研究一路做下來，真正最穩的結論不是「learner 已經全面超越 baseline」， 而是 `resource-cost` 與 `multi-feature` 已經明確比 `CQI-only` 更有辨識力。

為什麼不是 CQI

`CQI-only` 的限制已經很清楚

表面上相似，不代表成本相似

兩個使用者就算現在的 wideband CQI 很接近，實際上 RB profile 可能差很多。 對 multicast 來說，真正重要的是「要花多少 RB 才能穩定服務」，這就是 resource-cost 的角色。

歷史與動態不能忽略

使用者的 previous quality、歷史變化、移動方向，會影響 split 是否值得。 這些都不是單點 `CQI` 能完整表達的資訊。

現在的研究收斂句： 好的 grouping = 不只看「現在誰訊號差」，而是看「誰真的更耗資源、誰的服務狀態更容易互相衝突」。
Teacher 設計

為什麼 offline teacher 不找全域最佳解

這不是因為我們不想用更強的 teacher，而是全域 partition 搜尋成本太高。 若有 `n` 個使用者，要在 1 到 `Kmax` 群之間找 unrestricted 最佳分群，數量會跟 `Σ S(n, k)` 一樣快速爆炸。

理論上的全域搜尋

Σ S(n, k)

這是全 partition 的量級，對中型 scenario 也很難反覆拿來做 teacher labeling。

現在的 constrained teacher

Σ C(n - 1, k - 1)

先依 service difficulty 排序，再只搜尋 contiguous cut。 這不是全域最佳，但它夠強、可計算、可解釋，而且非常適合當研究中的 supervision target。

目前結論

現在最穩的三個方法層級

`CQI k-means`

作為起點很合理，也提供了一個重要對照組。 但它現在比較像最簡單、最容易失真的 baseline。

`Resource-cost k-means`

這是目前最有代表性的主 baseline。 它直接把「真實資源需求」帶進分群，所以比 CQI-only 更貼近問題本質。

`Multi-feature k-means`

這條線代表 richer feature 表示的上限方向。 它證明只要特徵設計夠完整，不一定非得靠 learned embedding 才能得到好的 grouping。

LE-GRA 的新定位

LE-GRA 不再是主角，而是探索性支線

它不是通解

LE-GRA 並沒有穩定地在各種 family、各種 corridor、各種 teacher split 型態下拉開差距。 多數情況下，它不是回到 parity，就是只在很窄的 regime 才有優勢。

但也不是完全沒價值

它至少幫我們找出一件事： 如果一個方法要超越 hand-crafted baseline，它必須處理的不是單純弱訊號，而是更細緻的邊界結構。

所以現在比較合理的研究定位是： 把 LE-GRA 留在 appendix 或 exploratory section，主文改用 resource-cost 與 multi-feature 作為主要貢獻線。

第一階段結論

這一輪研究真正留下了什麼

方法上的收穫

  • 建立了 teacher + DP 的完整比較框架。
  • 驗證了 `resource-cost` 是有內容、有意義的特徵表示。
  • 確認 `multi-feature` 是合理且值得保留的強 baseline。

研究上的收斂

  • 可以正式放棄「learner 必須是主角」這條敘事。
  • 可以把故事改寫成「從 CQI-only 走向 richer feature-based grouping」。
  • 過去的時間沒有白費，因為它幫我們證明了哪條路不值得繼續硬推。
一句話定位：這個專案的核心成果，不是做出一個穩贏的 learner，而是證明 `resource-cost / multi-feature` 比 `CQI-only` 更適合 multicast grouping。
