LE-GRA 故事版

把研究脈絡講成人話

這個專案在做的事情，可以先簡單理解成一句話： 我們想知道，在 5G vehicular multicast 裡，使用者分群能不能不只看 `CQI`，而是學到一種更接近「真正資源需求」的分法。

因為現實裡常常會出現一種狀況：兩個人表面上 `CQI` 很像，但實際上要把影片穩定送給他們， 所需要的 `RB cost`、歷史波動、移動趨勢都不一樣。LE-GRA 的想法就是， 不要只看表面的好壞，而是試著學出更深一層的 grouping 結構。

現在可以先記住的重點

這個研究不是還在空想階段。teacher、student、DP backend、ablation、 diagnostics 都已經跑起來，而且最新一次 `after_grad_fix` 重跑後， LE-GRA 已經在部分條件下贏過主要 baseline。

目前最重要的三個結論

  • `offline teacher + DP` 這條主線是對的，而且很強。
  • `resource-cost` feature 的價值很明確。
  • learner 修正後有進步，但在 `ambiguous` 場景還沒完全站穩。
研究故事

整個研究是怎麼一路長出來的

先造出可控的世界

你先用 synthetic scenario 去模擬 vehicular MBS，讓每個使用者都有 `CQI history`、`RB-level rate`、mobility、以及不同品質等級對應的資源成本。

再做一個很強但很慢的老師

`offline teacher` 不是線上部署用的演算法，而是用來產生高品質 pseudo-label。 它會先依照 service difficulty 排序，再搜尋可能的 grouping 邊界，最後用 exact DP 算出哪種 grouping 的 utility 最好。

接著訓練 student 去學這個老師

LE-GRA 的 learner 會把使用者特徵映射成 embedding，再用 `k-means` 做分群。研究的核心問題就是：這個 learned embedding，有沒有比手工 feature baseline 更會學到 teacher 的 grouping 邏輯？

最後統一丟進同一個 DP backend 評分

不管前面是 `CQI k-means`、`Resource-cost k-means`、`Multi-feature k-means` 還是 LE-GRA，最後都用同一套 DP allocation 來算 utility。這樣才能公平比較， 不會把 grouping 好壞和 allocator 差異混在一起。

為什麼 teacher 不找最佳解

不是不想找，而是全域最佳解真的太貴

這個問題你前面已經抓得很準：為什麼 offline teacher 不直接找全域最佳 grouping？ 答案就是，真的會太慢。

如果找全域最佳解

要枚舉所有可能 partition，搜尋空間是：

Σ S(n, k)

其中 `S(n, k)` 是 Stirling number of the second kind。這個量級對中型 scenario 來說就已經很難反覆拿來做 teacher labeling，更不用說還要配合訓練。

現在的 teacher 做法

先排序，再只搜尋 contiguous cut，候選數變成：

Σ C(n - 1, k - 1)

在固定 `Kmax` 的情況下，這個搜尋是 polynomial in `n`，雖然仍然不便宜， 但已經進入「可跑、可重現、可拿來訓練」的範圍。

所以你可以把現在的 teacher 理解成一個 可計算、可解釋、夠強的 constrained optimum。 它不是理論上的全域最佳解，但它是很好的 supervision target， 也正因為如此，LE-GRA 才有研究價值。

什麼叫 ablation

不是多跑幾組而已，是拆開問「到底哪個部件有用」

`ablation` 的意思，不是把模型亂拆，而是有目的地拿掉某些資訊或設計， 看結果會怎麼變。它的目的是回答： 這個方法有效，到底是因為哪個部分真的有貢獻？

`history_only`

只看 CQI history，代表最簡化的 learned input。

`history_cost`

在 CQI history 上加入 resource-cost，測試成本資訊到底有沒有幫助。

`full`

再把 RB statistics 與 mobility 加進去，檢查更多 feature 能不能再推高表現。

目前看起來，`history_only` 已經大致可以排除；真正值得競爭的是 `history_cost` 和 `full`。這代表 `resource-cost` 的價值很扎實， 同時也表示 richer feature 並不一定有問題，問題更可能在 learner 能不能把它們學好。

最新結果

`after_grad_fix` 之後，到底改變了什麼

這輪最重要的背景是：LE-GRA learner 先修正了 embedding L2 normalization 的梯度。 這不是單純 code cleanup，而是會直接改變訓練方向的 correctness fix。

有明顯變好的地方

在 `aligned/light` 與 `aligned/medium`，LE-GRA 已經贏過 `CQI k-means`、 `Resource-cost k-means` 和 `Multi-feature k-means`。

還沒完全解掉的地方

`ambiguous` 場景仍然最難，LE-GRA 雖然更接近強 baseline，但還沒有穩定形成明顯優勢。

研究結論的更新

以前比較像「LE-GRA 有概念但還沒證明自己」；現在已經進一步變成 「learner 真的有價值，但還需要更強才能在 ambiguity 下站穩」。

名詞對照

你現在最常碰到的術語，到底各自代表什麼

aligned

wideband CQI 和 RB-level 行為大致一致，代表比較「乾淨」、比較容易的場景。

ambiguous

wideband CQI 看起來相近，但實際 RB profile、mobility、歷史行為不同，這才是 LE-GRA 真正要證明自己的地方。

baseline

拿來公平比較的方法，例如 `No grouping`、`CQI k-means`、`Resource-cost k-means`、`Multi-feature k-means`。

pairwise_accuracy

看 student 與 teacher 對「兩個使用者應不應該分在同一群」的判斷有多一致。

ARI

Adjusted Rand Index，用來衡量兩個 clustering 的結構相似度，會校正隨機一致的影響。

NMI

Normalized Mutual Information，看兩個 clustering 共享多少資訊，越高代表越像。

utility

主要 QoE 指標，綜合 bitrate 效益、switching penalty 與未服務懲罰。

DP allocation

dynamic programming allocator，在既定 grouping 下找最好的品質配置。

offline teacher

很強但很慢的 supervision source，不是線上部署法，而是研究中的參考上界。

現在該做什麼

下一步不要亂擴，而是先把 learner 打磨好

1. 先把這輪結果當新基線

未來報告與討論，主結論應改引用 `medium_matrix_results_v2_after_grad_fix`。

2. 主攻 ambiguous 場景

因為 aligned 已經開始看到價值，真正還沒跨過去的門檻在 ambiguity。

3. 做 learner-focused 改進

優先考慮 validation selection、pair sampling、margin 與 epoch sweep，而不是先把矩陣加大。

一句話定位：teacher 已經很強，student 已經進步，但 learner 還需要在 ambiguous 場景證明自己。
現在最值得做的事：集中火力修 learner，而不是先擴大實驗規模。
