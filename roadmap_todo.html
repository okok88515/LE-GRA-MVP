LE-GRA MVP 待辦 Roadmap

這份頁面是給目前這個專案的實戰工作板。目標不是再擴充更多分支， 而是把研究主線收斂成一個能回答問題、能對老師交代、也能往論文延伸的結果。

你的核心任務可以濃縮成一句話： 先證明 LE-GRA 在哪些情境下有明確價值，再決定要不要把系統擴展到更真實的資料與更大的方法設計。

現在的判斷

專案已經完成 MVP 與初步實驗，但目前最需要的不是新功能，而是 主實驗、ablation、優勢區間 這三件事情的收斂。

今天先做

先把研究地基釘好

1. 固定主比較組

先把實驗比較方法鎖定為 `No grouping`、`CQI k-means`、 `Resource-cost k-means`、`Offline teacher`、`LE-GRA`。 `Pairwise graph` 先保留，但移到補充區。

目的：避免主線分散 輸出：固定方法清單

2. 定義標準實驗矩陣

決定之後每次都要跑的條件組合：`aligned / ambiguous / mixed` 搭配 `Kmax = 3, 4, 5, 6`，並固定 random seeds 與主要參數。

目的：建立可比較結果 輸出：實驗參數表

3. 規劃最小必要 ablation

先拆成三版： `CQI/history only`、`+ resource-cost`、`full feature`。 這一步是證明方法價值的關鍵。

目的：回答學到了什麼 輸出：ablation 設計草案

本週待辦

把主結果做乾淨

重跑主實驗

  • 對每個 scenario mode 跑完整 baseline 比較。
  • 每組條件至少跑多個 seed，避免單次結果過度偶然。
  • 整理成同一格式的 csv，欄位固定。

補齊 sensitivity

  • 先做 `Kmax` 敏感度。
  • 如果時間夠，再做 RB budget 與 switch penalty。
  • 目標是找出效能飽和點，而不是只多畫幾張圖。

產出一版可報告表格

  • 主表：方法比較。
  • 副表：ablation。
  • 圖：至少一張能看出 ambiguous 場景差異的圖。

下週要做

開始回答為什麼

1. 找出 LE-GRA 的優勢區間

不要求它所有設定都贏，但要明確定位它在哪些條件下比 `CQI-only` 或簡單 handcrafted baseline 更有優勢。

目標：找到可論述的亮點

2. 分析失敗情況

如果 LE-GRA 沒贏，要拆解原因： teacher 是否太強、contrastive loss 是否與 utility 錯位、 k-means head 是否限制太多。

目標：決定下一步改哪裡

3. 寫出三句研究論述

把研究故事壓縮成： `問題是什麼`、`現有方法缺什麼`、`你的方法在哪種情況有效`。

目標：讓報告與論文開頭更穩

本月方向

決定要收斂還是擴張

若主線穩定成立

開始往更 realistic 的資料來源推進，例如接 Simu5G / OMNeT++ traces，或逐步貼近你真正想做的 phase-2 allocation。

若主線仍不夠強

只發散一個方向，不要多開： 優先考慮改 `loss` 或 `grouping head`，例如讓學習目標更接近最終 utility。

不要優先投入的事

  • 不要先花大量時間做產品化介面。
  • 不要同時開太多新模型分支。
  • 不要急著全面重寫工程框架，除非研究結論已經成形。

最新進度

更新至 2026-08-07

1. `3|4|5|6 @ gnb_2` 線先停在明確瓶頸

`n5` 曾成功造出 early `ue5-only` 與 late `{ue4, ue5}` 的 temporal swap， 但 `n6 / n7 / n8` 都證明晚段 weak pair 很難撐成新的正增益 regime。 結論是：這條 family 可以做出有趣結構，但目前不適合再繼續微調。

狀態：已確認 plateau 決策：暫停深挖

2. `2|3|4|5 @ gnb_2` 新 family 第一版失敗

`o1 / o2` 顯示這條 family 雖然有弱候選輪廓，但第一版 primary-weak + light-decoy generator 連 split structure 都造不出來，因此目前不值得再花時間做局部小調整。

狀態：single-group only 決策：先不續做

3. `0|1|2|3|4 @ gnb_2` 成為新的主線 family

`o3` 確認 base regime 在 `18.7s ~ 19.2s` 有穩定正增益， teacher 會選 `[[0, 1, 2, 4], [3]]`，也就是穩定 isolate `ue3`。 這條線的價值是：它本來就有正增益，可以直接研究 structure perturbation。

狀態：正增益穩定存在 關鍵 window：18.7s ~ 19.2s

4. `o4 / o5 / o6 / o7` 找到新的 gain-structure 張力

`o4 / o5` 的 decoy injection 保住了原本正增益，但完全拉不動 structure； `o6` 第一次把 teacher 拉離 `ue3-only`，卻只得到 tie-utility multigroup； `o7` 嘗試直接做 dual-weak pair，又退回原本的 `ue3-only` 正增益解。

最重要發現：`o6` 會動 structure，但 gain 掉到 0 目前主 bottleneck：無法同時保住 gain 與新 structure

5. `o8` 已出現第一個 `{ue3, ue4}` 正增益 seed point

`o8` 在 `18.7s` 第一次出現真正可解釋的 `{ue3, ue4}` weak pair， 而且 `teacher_gain_vs_single = 0.012637...`，不再只是 tie split。 `o9` 與 `o10` 都證明這個 seed point 是可重現的，但目前還沒有被拉長成穩定 segment。

突破：首次 pair + positive gain 同時成立 限制：目前仍只有單一 timestamp (`18.7s`)

下一步待辦

只做高價值收斂項

待辦 1：以 `o8` 為中心做短窗口穩定化

下一個最值得做的方向不是再換 family，而是圍繞 `o8` 做 very local smoothing。 目標是把目前只出現在 `18.7s` 的 `{ue3, ue4}` 正增益 split， 拉成至少 2 到 3 個連續 timestamp 的短正向 segment。

待辦 1A：如果穩定化再失敗，就改做 ultra-short-window 驗證

如果接下來幾輪仍然無法把 `18.7s` 擴成短 segment，就不要再無限微調 teacher 端。 那時候應改成接受它是 single-point regime，直接做超短窗 learner-side 驗證， 測試這個 seed point 是否已足以拉開 teacher / baseline / LE-GRA。

待辦 2：先做 teacher-side focused validation，不先擴 learner

在還沒有得到「新 structure + 正增益」之前，不要先擴 learner matrix、 seeds 或 Kmax。先把 teacher regime 釘住，才有意義做後續 learner holdout。

待辦 3：如果 `o8` 穩定化成功，再進 focused learner

一旦 `o8` 附近出現可解釋的短正增益 multigroup regime， 就直接沿用 `18.7 ~ 19.2` 這個 segment 做 focused temporal learner， 優先檢查 teacher、LE-GRA、multi-feature、no-group 的差距是否終於被拉開。

先收斂

把主實驗、ablation、優勢區間做完整，這比增加更多方法更重要。

再發散

只有在知道瓶頸在哪裡之後，才選一條支線去調整 loss、head 或資料來源。

下一步建議

先從標準化實驗矩陣開始，因為那會決定你後面每一個判斷是不是站得住腳。

最新實驗補充

更新於 2026-08-07

`o8 @ 18.7s` 已確認可作為 single-point learner probe

針對 `p3_6o8_gain_recovery_bundle/bundle` 做 ultra-short-window 驗證後， 已確認這個單點本身就足以拉出 learner 與 baseline 的差異，不需要先等到更長的正增益 segment 才能做 focused learner study。

train end = `18.6s` test = `18.7s` only

`membership_order` 可追上 teacher，`kmeans_embedding` 仍掉回 no-group

同一個 `18.7s` probe 上，`membership_order` LE-GRA 與 offline teacher 同為 `0.6198214236671593`，但 `kmeans_embedding` LE-GRA 仍是 `0.6071841780840183`， 與 no-group 相同。這表示現在主要瓶頸是 grouping / inference bridge，而不是完全沒有學到 weak-pair 訊號。

teacher weak pair = `3|4` top-k prediction 也命中 `3|4`

`kmeans_embedding` 的具體失敗型態已確認：直接 collapse 成 single-group

最新 diagnostic 顯示，`kmeans_embedding` 不是把 `{3,4}` 分成錯的雙群， 而是最後整體退回 `0|1|2|3|4` 單一大群；相對地，`membership_order` 會得到 `3|4 / 0|1|2`，與 teacher 等價。這代表下一步應該直接研究 embedding 到 grouping 的橋接，而不是再懷疑 weak-pair 排名本身。

kmeans path: `0|1|2|3|4` membership path: `3|4 / 0|1|2`

最小 hybrid bridge 已在 `o8 @ 18.7s` 成功追回 teacher

新增 `hybrid_membership_kmeans` 後，LE-GRA 會同時考慮 weak-order 候選與 embedding k-means 候選， 再交給同一個 DP utility selector 挑最好的一個。這個最小 bridge 修正已在 `o8` 單點上成功回到 `3|4 / 0|1|2`，utility 與 teacher 完全一致，證明 bridge-level fix 本身就有價值。

new mode: `hybrid_membership_kmeans` result: utility gap = `0.0`

hybrid bridge 已通過第一輪 transfer check

`hybrid_membership_kmeans` 不只在 `o8 @ 18.7s` 成功，也已在 `m4b` 與 `m2` focused regime 上 直接追平 teacher。這代表目前最值得收斂的問題，已經不是再做更多 train-side 小 tweak， 而是正式比較不同 inference bridge，決定哪一個應該成為新的預設路徑。
